# D1.5 自主 Attention
## D1.5a：单头缩放点积注意力
Q[queries,d]、K[keys,d]、V[keys,value_dim]；先 K 转置，再 FP32 QKᵀ，乘 1/√d，稳定 Softmax 后 P×V，返回 context 与 probabilities。使用 D1.4 MatMul，可选 scalar、blocked、Auto、Parallel；QKV 是已投影输入，未加载权重。Softmax 最后一轴减最大值，FP64 exp/sum，结果 FP32；输入 Tensor 必须有限，FP32 中间矩阵溢出报错。mask 为 bool keep（true 可见），key padding、pair mask、causal offset 取交集。全 mask 行概率与 context 均为0，明确不是普通 softmax 的概率分布；keys=0、d=0、value_dim=0 拒绝，queries=0 允许。资源限制复用 Tensor/MatMul；无 dropout、梯度、加性 bias、KV cache 存储、批处理或 fused kernel。
NumPy 2.3.5 独立 FP64 参考在研发环境生成：q=[[1,0],[0,1]], k=[[1,0],[0,1],[1,1]], v=[[2,4],[6,8],[10,12]]；计算 q@k.T/sqrt(2)，减行最大值，exp/行和，乘 v。无 mask 输出 [[6,8],[6.81334511,8.81334511]]；最后一 key mask 输出 [[3.3209538,5.3209538],[4.6790462,6.6790462]]。独立数组嵌入 Rust tests，比较 2e-6 + 2e-6*abs(reference)；极端 logits、全 mask、形状错误、增量 offset 和非有限结果测试。CI 不依赖 Python。性能和真实模型尚未测试。D1.5b 继续多头、QKV 投影、LayerNorm。

## D1.5b：投影、多头与归一化
新增 layers.rs：Linear 权重 [out,in]、可选 bias；多头单序列 self/cross attention，Q 与 memory 分别投影、按 head 切分，复用 D1.5a mask 与计算，串行逐头、合并 context 后输出投影。head 1–128、整除 model width，限制总 attention MAC；不保留跨头概率，不含批处理、缓存、dropout、训练。全 mask context 为零，输出投影仍可有 bias。LayerNorm 末轴 FP64 均值、population variance、epsilon>0、affine，输出 FP32；residual_norm 严格同形状并执行 post-norm。实际 NumPy 2.3.5 独立 FP64 参考使用2 query、3 key、4 hidden、2 head、非恒等 Q/V/输出权重及 key mask，计算 QK^T/sqrt(2) 后 softmax×V、concat、输出投影及 residual LayerNorm；参考值嵌入 Rust 测试，绝对+相对容差3e-6。尚无真实 checkpoint 或模型速度验证，CI 待验收。
