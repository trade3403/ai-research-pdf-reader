# D1.7 自主自回归生成
## D1.7a
search 接收 logits 回调，严格 [1,vocab] finite FP32；FP64 max-subtracted log-softmax，原始模型概率归一化后剔除 suppress、最小长度前 EOS、可选末步强制 EOS（不把 EOS 概率改为1）。beam 1 为 greedy，1–16 beam、1–512 新 token、vocab<=200000，length penalty 0–2；长度包含 EOS、不含 start。每个活动候选选择最多 B 个 token（partial selection），全局统一排序并保留最多 B 个候选，完成序列原样保留、不扩展；按累计 logp / generated_length^penalty 排序，平分按完整 token 序列字典序。到全结束或上限停止，未结束显式 ended=false。返回 token 序列包含 start。该策略非 Hugging Face BeamSearchScorer 精确等价（完成候选池、早停、长度策略及 forced EOS 分数可能不同），D1.7b 需独立对照与真实配置适配。Encoded::generate 复用 source memory，每步重算 decoder prefix，暂未 KV cache。限制单次生成步数不得超过 decoder max_positions。固定 logits 概率测试、beam 优于 greedy 的样例、EOS/长度、平分、非有限/边界及合成模型入口测试；无外部 Rust 依赖。未验证真实权重、翻译质量或速度。

## D1.7b1：KV cache
每层 self K/V 保存已处理位置的投影，只计算新 token 的 Q/K/V、FFN、norm；cross K/V 预投影一次、Rc 共享。不可变快照逐步追加 K/V（复制旧行，非原地或分页 cache），分支不修改父级，失败不污染已有快照。源 mask 与 target keep 分开，位置 offset 按已处理 token 数。generate_cached 仅保存上一深度和当前深度的活动前缀快照，复用原 search 策略。预算保守限制 (source+(2B+1)*max_steps)*hidden*layers*8 <=256MiB，仅缓存数据区，不是进程总内存。单序列、CPU、<=512步骤，未做速度实测、未实现 HF beam scorer 等价、真实权重或分页缓存。cached_logits 对照完整 prefix 与独立 PyTorch Marian；1/2/4 beam 对照全前缀 token/score/EOS，实际验收：[修复代码 08be738](https://github.com/trade3403/ai-research-pdf-reader/commit/08be738a82ef91a8b278fe84546ae0e5712de81e)，[复测 45528484279](https://github.com/trade3403/ai-research-pdf-reader/actions/runs/45528484279) completed/success；首轮9组 rustfmt 修正；基础 CPU CI 与独立 PyTorch/Marian 对照通过，240张量、4744元素，整体 max_abs=4.76837158e-7，cached_logits max_abs=1.78813934e-7，1/2/4 beam 缓存与完整前缀一致。未测速度及真实模型。

## D1.7b2：独立文本生成验证
独立 PyTorch 小 Marian 模型，以 FP64 log_softmax 和每步全量候选枚举、全局排序模拟明确的自主 beam policy（非复用 Rust partial top-k）。3 源输入、beam 1/2/4、两种长度/forced EOS 设置、full/cached，两条 Rust 路径比较返回所有 token IDs、EOS、累计 logp 和 length penalty score（atol/rtol 1e-5）；直接 Transformers generate 额外对照 greedy 三组。MarianGeneration 映射 total max_length 到 max_new=max_length-1，min_length 到 min_new（当前前缀长度=步号），pad 不自动 suppress，forced EOS 必须与 EOS 相同。固定 OPUS-MT 元数据由独立 Runner 下载并记录哈希、有效配置及 unsupported processors；仅适配受限确定性生成字段，不保证 HF beam scorer、early_stopping、强制 EOS 评分等价，真实翻译与质量 D1.8 后验证。Python 仅研发参考，不进入运行时。
