# D1.7 自主自回归生成
## D1.7a
search 接收 logits 回调，严格 [1,vocab] finite FP32；FP64 max-subtracted log-softmax，原始模型概率归一化后剔除 suppress、最小长度前 EOS、可选末步强制 EOS（不把 EOS 概率改为1）。beam 1 为 greedy，1–16 beam、1–512 新 token、vocab<=200000，length penalty 0–2；长度包含 EOS、不含 start。每个活动候选选择最多 B 个 token（partial selection），全局统一排序并保留最多 B 个候选，完成序列原样保留、不扩展；按累计 logp / generated_length^penalty 排序，平分按完整 token 序列字典序。到全结束或上限停止，未结束显式 ended=false。返回 token 序列包含 start。该策略非 Hugging Face BeamSearchScorer 精确等价（完成候选池、早停、长度策略及 forced EOS 分数可能不同），D1.7b 需独立对照与真实配置适配。Encoded::generate 复用 source memory，每步重算 decoder prefix，暂未 KV cache。限制单次生成步数不得超过 decoder max_positions。固定 logits 概率测试、beam 优于 greedy 的样例、EOS/长度、平分、非有限/边界及合成模型入口测试；无外部 Rust 依赖。未验证真实权重、翻译质量或速度。CI 待验收。
