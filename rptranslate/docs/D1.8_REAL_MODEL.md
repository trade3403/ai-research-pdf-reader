## D1.8b 分块词表（待验证）
RowTable 为密集 Tensor/ChunkedTable 的 sealed 只读行接口；内部 rpmodel Safetensors reader 分段读取 FP32/FP16/BF16 后转 FP32，最多1M元素每块，行数<=200000、宽<=8192、单表<=512MiB且显式调用者预算。块保持 Tensor 原64MiB上限（每块最多4MiB），可共享借用同一表用于编码、解码及 tied LM Head；分块按全局 ID 查找，投影按行 FP32 标量点积，避免全表合并或转置；输出 Tensor/MAC 上限不变。合成65001×512实际分配测试（32块，133122048 bytes）及全65001 logits 精确校验；小 Safetensors fixture、错误形状/预算/非有限值检查，独立小 Marian 参考改用分块共享词表。未验证真实 checkpoint 分块读取、性能或 INT8；驻留分块不是 mmap，预算仅 payload，不是总 RSS，完整真实权重映射留 D1.8c。
