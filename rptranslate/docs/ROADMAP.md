# D 线路研发路线与阶段门槛

日期：2026-11-24。顺序：先 GitHub 免费 Runner → 本地电脑 → 软件集成。阶段编号按能力验收，不按日历或代码量。除 D1.0 外均为计划，允许经实测调整。

## D1：免费 Runner 基础研发
| 阶段 | 实现内容 | 阶段验收 |
| --- | --- | --- |
| D1.0 | 四 crate、基础语料验证、点积、模型预算、CI | 基线编译/测试成功；明确模型未就绪 |
| D1.1 | Safetensors 自主解析、dtype/shape/offset、FP32/FP16/BF16 | 合法小权重 fixture 精确读取；截断、越界、重叠、溢出拒绝 |
| D1.2 | 选定预训练模型的分词器、Unicode 和特殊 token | 对照参考 tokenizer 的英中、空白、符号 token ID；往返行为一致 |
| D1.3 | Tensor、shape/stride、广播、基础逐元素计算 | 正常/非法形状、有限数、基准值测试 |
| D1.4 | 矩阵乘法、SIMD/AVX2、多线程 | 与 FP32 标量参考误差对照，非 AVX2 回退 |
| D1.5 | Attention、mask、softmax、归一化 | 固定输入逐算子比对，极端值/掩码稳定 |
| D1.6 | Encoder/Decoder、FFN、embedding、cross-attention | 玩具模型逐层输出对照；真实架构兼容性逐步验证 |
| D1.7 | Beam Search、EOS、长度限制、缓存 | 固定 logits 解码结果、终止条件、确定性测试 |
| D1.8 | 合法开放英中模型（Marian/OPUS-MT 候选） | 校验来源/许可/权重、真实翻译、与参考实现比较 |
| D1.9 | INT8 权重量化和反量化、整数/混合精度计算 | 误差、体积、CPU 时间及质量对照；不合格回退 |
| D1.10 | 术语、数值、单位、公式、引用保护 | 占位符完整性，错误提示及人工核查；不静默改变数据 |
| D1.11 | 真实科研论文离线小样本评估 | 独立授权样本；模型质量、完整性、时延、内存报告 |
| D1.12 | 小规模训练脚本、确定种子、断点续训 | CPU toy fixture 上 loss/更新及恢复一致性；不是正式训练 |
| D1.13a | Windows x64 原生映射、基础回归及真实 INT8 翻译 | 标准 Windows Runner，逐位映射对照、损坏拒绝、auto/portable 翻译相等 |
| D1.13b | Windows FP32 与核心部署、配置及离线验收 | Windows 标准 Runner 实际 FP32、依赖及部署检查，不调用用户机器；正式训练工具归独立 RPDistill |

D1.8 后真实模型测试需限制样本/运行时间和存储。下载在独立准备步骤，明确授权与 checksum；真正推理测试禁用在线服务。若资源不足，保留小规模 CI 和显式待本地测试项，不放宽验收为假通过。

## D2：本地训练与优化
参考硬件：Ryzen 7 8840HS、Radeon 780M、约 64 GB RAM；非 CUDA 独显平台。以下配置仅为研发参考，性能待测。
| 阶段 | 工作 | 阶段验收 |
| --- | --- | --- |
| D2.0 | CPU/Vulkan 能力检测、性能基准 | 报告可用后端、内存、速度、温度与失败回退 |
| D2.1 | Qwen3 4B INT4 教师基准，8B 候选比较 | 小样本译文质量和吞吐实测，选更合适模型 |
| D2.2 | 本地教师生成语料；先百条试点再 1 万条 | 来源可追溯、任务可暂停、无外部 API、断点恢复 |
| D2.3 | 双语对齐、去重、术语/数值校验、人工抽检 | 数据质量报告及固定验证/测试集 |
| D2.4 | Marian 类预训练学生模型专业微调 | 相同测试集与未微调基线比较 |
| D2.5 | 序列级知识蒸馏（教师译文作监督） | 蒸馏学生与普通微调对照；不必同时载入教师/学生 |
| D2.6 | INT8 量化，必要时蒸馏小架构或剪枝 | 权重大小、内存、速度与质量回归报告 |
| D2.7 | RPModel 候选模型包及模型卡 | 权重哈希、许可证、训练数据说明、可复现配置 |
| D2.8 | 跨学科真实论文测试 | 人工评估和自动指标；不通过则不发布 |
| D2.9 | AMD NPU 研究（可选，不阻塞发布） | 可用性及数值/速度对照，失败保留 CPU |

本地训练优先小批次、梯度累积、短序列、断点保存，先测试耗时；GPU 训练框架不兼容时采用 CPU 小规模试验或经用户另行同意的外部 GPU。百万句对为长期方向，不保证单机可接受时间内完成。

## D3：发布与主程序集成
1. D3.0：独立模型管理、首次按需下载/离线导入、校验、升级与卸载。
2. D3.1：A/B/C 接口，PDF/Word 选段翻译、双语对照、任务取消，默认离线。
3. D3.2：全文翻译、段落映射及双语导出；保留原文和科研数值。
4. D3.3：Windows 安装包、真实 GUI 测试和演示视频（有实际 GUI 后）、模型单独发布。
5. D3.4：基于真实反馈扩展学科/语言、性能优化，研究从零训练的可行性。

## 依赖与难点
D1.1→D1.8 是可运行模型关键路径；D1.9 量化以正确 FP32 基线为前置；D1.10/D1.11 可部分并行。D1 全部适用门槛通过再转 D2；正式训练、长期生成、GPU/NPU 实测不使用免费 Runner。D3 必须有可验证模型质量，不以编译成功替代产品验收。


## 当前路线补充（2026-11-26）
D1.11 首批新增文档级覆盖审计，具体门槛见 PROGRESS 与 HANDOFF。用户明确 D2 教师训练/蒸馏为独立 RPDistill 项目，不纳入本分支剩余阶段；D1.12 只保留固定CPU toy数学及断点恢复验证，不承担真实模型训练或蒸馏；正式训练由独立RPDistill项目承担。D1.11 自动词面与工程验收不代替人工双语语义审核，不作为直接发布依据。
