# D 线路研发路线与阶段门槛

日期：2026-11-24。顺序：先 GitHub 免费 Runner → 本地电脑 → 软件集成。阶段编号按能力验收，不按日历或代码量。除 D1.0 外均为计划，允许经实测调整。

参考硬件：Ryzen 7 8840HS、Radeon 780M、约 64 GB RAM；非 CUDA 独显平台。以下配置仅为研发参考，性能待测。

## 依赖与难点
D1.1→D1.8 是可运行模型关键路径；D1.9 量化以正确 FP32 基线为前置；D1.10/D1.11 可部分并行。D1 全部适用工程门槛通过后转 D3.0；D2由独立RPDistill项目推进；正式训练、长期生成、GPU/NPU 实测不使用免费 Runner。D3 必须有可验证模型质量，不以编译成功替代产品验收。
