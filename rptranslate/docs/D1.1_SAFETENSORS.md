# D1.1 自主 Safetensors 权重解析

参考：[Safetensors 格式说明](https://github.com/safetensors/safetensors#format)、[Hugging Face metadata parsing](https://huggingface.co/docs/safetensors/en/metadata_parsing)。本模块按公开格式独立实现，不依赖 safetensors Rust crate。

格式：8 字节 little-endian header length，UTF-8 JSON header，以 data buffer 为基准的半开区间 offsets，连续无空洞数据。metadata 只接受字符串键值；拒绝重复键。支持 FP32、FP16、BF16（IEEE 特殊值保留，由计算层判断）。shape 空数组为标量，含零维度为零元素。元素计数、字节数和位置校验，拒绝不支持 dtype、损坏头、重叠、空洞、截断和尾随数据。

资源上限：8 MiB header，100000 顶层条目/metadata 条目，rank 16，每次读取最多 1048576 元素。Read+Seek 只读取索引和指定切片，适合 File 或 Cursor；不使用 mmap，不加载整文件。仅支持稳定未修改的本地文件，未实现并发文件篡改检测、checksum、分片索引、其他 dtype 或真实模型加载。

## 参考样本
reference.hex 是利用 Python safetensors 0.7.0 serialize 生成的合成文件（非第三方模型权重），测试无需 Python。重建方式：
```python
import struct
from safetensors import serialize
b = serialize({
    "a": {"dtype": "float32", "shape": [2], "data": struct.pack("<ff", 1.25, -2.5)},
    "b": {"dtype": "float16", "shape": [2], "data": struct.pack("<HH", 0x3c00, 0x0001)},
    "c": {"dtype": "bfloat16", "shape": [], "data": struct.pack("<H", 0xbf80)},
}, metadata={"source": "reference"})
print(b.hex())
```
字段顺序可能因序列化实现而变化，测试关注实际读取值、元数据、切片、非法输入和 half 边界。真实大模型兼容性、吞吐、内存峰值待后续测试。D1.1 不提供翻译能力。
