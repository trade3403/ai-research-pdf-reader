# D1.10f — Audited paragraph translation

Status: code submitted, CI pending.

- Opt-in Rust TextSession::translate_paragraph and CLI translate-paragraph[-int8] MODEL_DIR DOMAIN TEXT [BEAM_WIDTH] [MAX_NEW]; auto builds an immutable paragraph-level domain prior. Strong local evidence overrides it, weak/mixed follows the prior D1.10d abstention policy. This is glossary context consistency, not neural cross-sentence attention.
- Conservative sentence boundary scan outside recognized literals and brackets; abbreviation list and decimals guarded. If a sentence exceeds 192 source tokens (including special tokens), greedily group safe comma/colon/semicolon clauses; reject an indivisible long clause. Max 64 chunks and 64 KiB input. UTF-8 source ranges, newline-separated results, no silent truncation.
- Candidate priority: unmodified whole-source output, whole-source ordered constraint output, then existing protected-gap path. Each candidate must pass exact ASCII numeric multiset, longest non-overlapping target occurrence counts, known scoped erroneous term residues, and repeated identical clauses (6+ characters). Missing or excess surfaces fail; number order not checked. No deletion, semantic correction, or acceptance of partial paragraph; all failure reasons recorded. Fallback can still lose context.
- Limitations: lexical audit may reject valid translations (reordering of numbers allowed but equivalent numeric formats rejected, valid repeated clauses or scoped terms may be flagged); unrecognized errors, incorrect relations and grammar may pass. It does not measure semantic adequacy. No change to defaults or old APIs, no dependency/model training.
- Unit tests for literal/abbreviation boundaries, safe long split, numeric duplication, overlapping targets, observed error residues, repeated clauses, context prior, fallback and fail-closed. Actual FP32/INT8 two fixed paragraphs each, numeric accepted-clean or explicit rejection, tiny-budget negative and eight paper sample observations. No fabricated quality percentages. All prior gates retained.
