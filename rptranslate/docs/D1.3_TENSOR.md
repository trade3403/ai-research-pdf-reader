# D1.3 自主 FP32 Tensor
独立 Rust dense owned row-major 张量。rank 0 表示标量、含 0 轴可为空；rank <=16、每轴及每个后缀元素乘积 <=16,777,216；单个 FP32 数据区最多 64 MiB（不含元数据、输入与输出并存）。使用 checked_mul 和 try_reserve_exact；拒绝长度/形状不匹配、非法轴、索引越界、NaN/Inf、除零和运算溢出。无 unsafe 或第三方运行依赖。
- Shape/stride：最后一轴 stride 1，前轴按后缀乘积计算。
- Reshape：同元素数下仅更新元数据，不移动数据；失败保持原张量。
- Permute：完整轴排列，生成新的连续张量，不返回别名 view。
- Broadcast：从末尾对齐，维度相等或一方为1；扩展轴 stride 0，包含标量、0轴。
- Add/Sub/Mul/Div：逐元素 FP32，结果有限性检查。
- 测试：布局、索引、reshape 分配复用、3D permutation、双输入广播、标量、空张量、非法输入。
独立参考数组在研发环境由 NumPy 2.3.5 实际生成：
```python
import numpy as np
a = np.arange(1,7,dtype=np.float32).reshape(2,1,3)
b = np.array([10,20,30,40],dtype=np.float32).reshape(1,4,1)
print((a+b).ravel(), (a*b).ravel())
print(np.arange(24,dtype=np.float32).reshape(2,3,4).transpose(2,0,1).ravel())
```
Rust 单元测试嵌入参考数组；CI 不需要 NumPy。当前不支持 strided view、任意 dtype、矩阵乘法、SIMD、并行、自动微分或 GPU；性能尚未实测。单张量上限需在实际模型加载阶段根据最大权重和可用内存重新设计。
