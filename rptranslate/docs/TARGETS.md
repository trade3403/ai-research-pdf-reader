# RPModel / RPTranslate 研发目标与验收

日期：2026-11-24。下列量化指标是建议目标，尚未实际测量，后续以对照报告修订。

## 产品目标
- 科研英译中为首版方向，后续双向及其他语言另行评估。
- 用户模型安装后可断网翻译；无在线翻译 API、API Key、强制账号或按次接口费用。首次下载可联网或从本地文件导入。
- 最终 CPU 核心 Rust 原生运行，不要求 Python、PyTorch、教师大模型、独显或 NPU。
- 普通电脑轻量离线翻译为主，GPU/NPU 可选；不牺牲科学事实换取更流畅译文。
- 与 A/B/C 独立接口集成，保持原文、公式、统计量、单位、引文和段落定位。

## 模型与部署指标
| 指标 | 初期目标 | 验收方法 |
| --- | --- | --- |
| 教师 | Qwen3 4B INT4 起步，8B 候选 | 译文人工抽检、吞吐/内存实测 |
| 学生 | 5000 万–1 亿参数目标；Marian 类预训练基线 | 实际模型结构/参数统计；若基线更大先如实记录 |
| 学生 INT8 权重 | 约 50–120 MB | 实际权重文件及完整模型包分别测量 |
| CPU 推理核心 | 目标 20 MB 左右 | Windows release 二进制及额外运行库分别计量 |
| 安装包 | 主程序与模型分离 | 安装包/模型/缓存/运行库磁盘分别统计 |
| 普通 CPU 运行 | 不强制 GPU，8 GB RAM 电脑为目标测试档 | 冷启动、峰值 RSS、每段/整篇延迟、吞吐 |
| 学术语料 | 先 100 条试点，再 1 万条；10 万/100 万逐步评估 | 经清洗、许可证核实的有效句对计数 |
| 训练 | 断点续训、可重复配置 | 训练 seed、配置、日志、checkpoint 对照 |
| 离线 | 翻译环节 0 网络请求 | 禁网测试、检查调用路径，记录运行环境 |

50–120 MB 是学生权重目标，不是主程序大小。100M × 8bit 理想权重约 100 MB，实际还包括量化元数据、词表、模型配置及额外运行内存。模型体积、速度与质量取舍以实测为准。

## 质量验收设计
1. 固定有许可的英中测试集，按论文/来源划分，与训练数据去重；覆盖计算机、材料、医学/生物、化学、物理、工程及长句/公式/表格。先建立小基线，规模和参考译文质量记录在测试报告。
2. 对照未微调开放模型、教师和 RPModel FP32/INT8。同一文本、分词版本、解码配置，记录 BLEU/chrF（工具版本和参数），可选经验证的 COMET；自动分数不能直接换算成准确率。
3. 人工评价语义忠实度、专业术语、语言可读性，记录抽样方法、错误等级、漏译及幻觉。严重科学事实错误列为阻塞问题。
4. 建议验收门槛：保护用例中公式/数值/单位/引用完整恢复率 100%；保护失败显式报警，不伪造译文。该门槛仅针对定义明确的保护测试，不保证所有自然文本 100% 正确。
5. 测量量化前后相同测试集的质量和速度；允许误差和最低分数在 D1.11 基线形成后确定并冻结，不在无数据时编造准确率。
6. 数值算法逐层对照：按 dtype/算子预先定义绝对和相对容差；记录误差而非仅 PASS。无效模型或超资源必须失败可诊断，取消任务不破坏原文。
7. 最终包进行无网络、干净 Windows 环境测试；记录最低硬件、真实安装体积、峰值内存、性能及缺陷。发布门槛需用户确认后冻结。

## 资源目标
优先零额外预算：公开仓库标准托管 Runner 做有限 CI、本地电脑承担小规模语料生成及训练。免费资源可用性、显卡兼容性及训练耗时不保证；不购买服务、不使用收费 Runner 或自动外部训练，除非用户另行批准。
