# RPModel v1（固定 Marian FP32 profile）
目录格式，不发明新的二进制容器。weights.safetensors 采用标准 Safetensors，FP32 little endian、原始 Marian 名称和 shape；配置、生成配置、source.spm、target.spm、vocab.json 原字节保留。manifest.json UTF-8，format=RPModel、version=1、source、revision、license、checkpoint_sha256、dtype、tensor_count、payload_bytes、aliases、files（每文件 bytes/SHA256）；manifest 不对自己哈希，不提供签名或信任链，未来运行时须验证受信任来源/哈希。权重 metadata 字符串 format=pt、rpmodel_format=1、source_revision、source_sha256。固定官方 revision a4193836671069f1f80ce341f9227a850ffb52d4（Apache-2.0 模型卡），312087009 bytes checkpoint SHA256 69a1d6ec829cee349360b3b677ac0aa99a7d88822d1a6578370029efffdca3f5；5个其他文件也严格按 D1.8a 已核验哈希与大小。
- 输入258张量严格名称、shape、FP32、contiguous、finite；仅 torch 2.6.0 CPU weights_only=True，无 unrestricted fallback。离线输入目录须稳定，不处理任意陌生 checkpoint。
- model.encoder.embed_tokens.weight、model.decoder.embed_tokens.weight 与 model.shared.weight 逐位相等后去重；manifest aliases 显式映射，LM Head 后续借用 shared（原权重无独立 lm_head）。保留两个位置表 [512,512] 及 final_logits_bias [1,65001]，后续加载再逻辑展平 bias。
- 256 canonical tensors，预期 payload 312033188 bytes（78008297 FP32 元素），不是压缩或量化。保存到同一父目录临时目录，成功后 rename 为新目录；单进程、可信本地目录，不提供多写者事务保证。不上传权重。
- 研发转换依赖 torch 2.6.0、safetensors 0.7.0、numpy 2.2.6；运行时 Rust reader 自主。CI 使用官方读取器逐张量对照原始权重，再通过 Rust read_f32 每次<=1M元素输出排序后的 little-endian bytes，Python 逐块比较所有位，检查 EOF 与退出码。Rust 示例为研发检查器，不是完整运行时 loader。实际转换与 roundtrip 结果待 CI；完整 manifest 自主解析、校验、权重映射、模型实例、推理及性能留后续。
