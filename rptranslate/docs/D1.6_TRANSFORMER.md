# D1.6 自主 Transformer
## D1.6a：输入与 FFN
- Embedding 从 [vocab,hidden] 按 token ID gather，显式 scale（模型配置决定 1 或 sqrt(hidden)），保留实际 padding 权重行；非法 ID、非有限数、超 Tensor 上限拒绝。
- Marian 位置编码采用 grouped sin/cos（奇数 hidden 时 sine 多一维），不是标准交错布局。对照 [Transformers v4.48.3 MarianSinusoidalPositionalEmbedding](https://github.com/huggingface/transformers/blob/v4.48.3/src/transformers/models/marian/modeling_marian.py)。支持 offset 和 max_positions（最多1048576），FP64 计算后输出 FP32，不含真实 checkpoint 读取。
- FFN 使用 [out,in] Linear、可选 bias、ReLU/GELU tanh approximation/SiLU；不实现 erf GELU、dropout 或反向传播。残差及 norm 在 Encoder/Decoder 层组装。
- NumPy 2.3.5 在研发环境实际生成参考：位置 p=0,1,2，hidden=4，角度 p/(10000**(2*arange(2)/4))，拼接 sin 和 cos；FFN x=[[1,-2],[3,4]], W1=[[1,2],[-1,1],[0.5,-0.5]], b1=[0.5,-0.5,1], W2=[[1,-2,0.5],[0,1,2]], b2=[0.25,-0.25]，ReLU 输出 [[1.5,4.75],[11,1.25]]。测试嵌入固定数组，四种矩阵路径；不依赖 Python 运行时。
- 本阶段不包含完整 Encoder/Decoder、KV cache、模型加载或翻译性能。后续需逐层对照真实 Marian 架构及配置。

## D1.6b：Encoder
单序列 post-norm EncoderLayer：self-attention→residual/norm→FFN→residual/norm。Norm 复用 D1.5，encode_hidden 顺序执行1–64层，不保存全部中间状态；Encoder::forward 从 token IDs 加 embedding/Marian position。key_keep 每层传播，padding_mask 显式生成，不自动屏蔽 query rows。合成输入 3×4、2 heads、2 layers（重复权重用于 fixture）、FFN inner=3、非恒等权重与 affine norm；独立 NumPy 2.3.5 FP64 参考生成脚本 `crates/rpinfer/tests/encoder_reference.py`，实际生成数组内嵌 Rust 测试，容差 1e-5 + 1e-5*abs(reference)，四矩阵路径。测试有效位置对被遮罩 token 的不变性、ID/shape/空序列错误与 embedding 入口。未实现 decoder、batch、训练、真实权重、KV cache 或实际性能。
实际验收：首轮 [45518807677](https://github.com/trade3403/ai-research-pdf-reader/actions/runs/45518807677) rustfmt 失败，修正13组格式；第二轮 [45518859608](https://github.com/trade3403/ai-research-pdf-reader/actions/runs/45518859608) Clippy 指出 FP32 参考常量 excessive_precision，按 FP32 表示修正，不改变测试容差；[最终代码 513bfa1](https://github.com/trade3403/ai-research-pdf-reader/commit/513bfa15639d3a1b96cb8f35b49c3204c3eb38ef)，[复测 45518927770](https://github.com/trade3403/ai-research-pdf-reader/actions/runs/45518927770) completed/success。两层 Encoder 参考对照、mask 隔离、embedding 入口和边界测试通过，workspace 格式、Clippy、测试、Release、自检与 portable-only 通过。未加载真实模型、未测推理性能，D1.6b 通过，D1.6 整体尚未验收。

## D1.6c：Decoder
单序列 post-norm self attention（始终 causal offset=0）→cross attention（encoder memory，无 causal）→FFN，各段 residual norm。显式源/目标 key mask，1–64 层 full-prefix 重算，不提供 KV cache、batch、训练或真实权重。目标 PAD ID 不自动屏蔽，避免 Marian decoder start 与 PAD 共用时隐藏起始 token。NumPy 2.3.5 FP64 独立参考实际生成，重建脚本 `crates/rpinfer/tests/decoder_reference.py`；3×4 隐藏、2 heads、2 层、非恒等投影、源 mask，参考数组保留6位小数，容差 1e-5+1e-5*abs(reference)。测试四种矩阵路径、首层三个输出及双层结果、未来 token 隔离、prefix 一致性、源和目标 padding 隔离及错误输入。CI 待验收，未测真实性能。
