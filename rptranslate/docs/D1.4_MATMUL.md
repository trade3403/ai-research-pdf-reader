# D1.4 自主矩阵乘法和 CPU 加速
## D1.4a：便携标量与分块
A[M,K] × B[K,N] → C[M,N]，row-major FP32；标量 i-j-k 基准与 32×32×32 cache blocking，内层连续 j 访问。两者按同一 K 顺序累加，不显式使用 FMA。支持非方阵、非32倍数、零轴、K=0 时全零输出；拒绝形状不匹配、输出超张量上限、超过 2^30 MAC 的单次计算以及非有限结果。复用 Tensor 的有界分配，无 unsafe 和第三方运行库。
数值门槛：固定 2×3×2 手算参考；四组非方阵含尾块，对照独立 f64 累加，绝对+相对容差 1e-5；标量与分块结果逐元素相等。资源上限和异常输入必须通过。实际性能用 release 示例，128/256 方阵、预热、各三次中位数（含输出分配、有限性检查；不含输入构造）。记录 Runner CPU 和实际时间，不能外推本地机器，也不以加速倍数作为不稳定的 CI 门槛。
当前未实现 AVX2、FMA、线程并行或 batched matmul；D1.4b 继续实现并测试实际 CPU 特性和回退。完整阶段待验收。
