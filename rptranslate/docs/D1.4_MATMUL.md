# D1.4 自主矩阵乘法和 CPU 加速
## D1.4a：便携标量与分块
A[M,K] × B[K,N] → C[M,N]，row-major FP32；标量 i-j-k 基准与 32×32×32 cache blocking，内层连续 j 访问。两者按同一 K 顺序累加，不显式使用 FMA。支持非方阵、非32倍数、零轴、K=0 时全零输出；拒绝形状不匹配、输出超张量上限、超过 2^30 MAC 的单次计算以及非有限结果。复用 Tensor 的有界分配，无 unsafe 和第三方运行库。
数值门槛：固定 2×3×2 手算参考；四组非方阵含尾块，对照独立 f64 累加，绝对+相对容差 1e-5；标量与分块结果逐元素相等。资源上限和异常输入必须通过。实际性能用 release 示例，128/256 方阵、预热、各三次中位数（含输出分配、有限性检查；不含输入构造）。记录 Runner CPU 和实际时间，不能外推本地机器，也不以加速倍数作为不稳定的 CI 门槛。
当前未实现 AVX2、FMA、线程并行或 batched matmul；D1.4b 继续实现并测试实际 CPU 特性和回退。完整阶段待验收。

实际验收：[代码 9515ca5](https://github.com/trade3403/ai-research-pdf-reader/commit/9515ca57909aa9cc4ff64ca3dc8411a065a36af5)、[Actions 45515952092](https://github.com/trade3403/ai-research-pdf-reader/actions/runs/45515952092) completed/success。4 项 MatMul 新测试及全部 workspace 35 项单元测试通过（3+11+19+2），格式、Clippy、Release、自检、矩阵基准通过。Runner Intel Xeon Platinum 8573C，4 vCPU，release 3 次中位数：128 方阵 scalar 1.620ms / blocked 0.328ms，4.944x；256 方阵 20.304ms / 2.724ms，7.453x。两路径结果完全相等（exact=true）；仅该次共享 Runner、该合成输入，不代表实际模型或本机性能。未实施显式 SIMD 或多线程，完整 D1.4 待验收。

## D1.4b：AVX2 与线程并行
x86_64 默认编译便携二进制，运行时 `is_x86_feature_detected!("avx2")` 后调用隔离的 target_feature 内核；8 个 FP32 元素向量 load/mul/add/store，不显式使用 FMA，尾部标量，保持 K 累加顺序。unsafe 仅限特性调用及有界8元素不对齐访问。portable-only Cargo feature 强制排除 AVX2，其他架构自动分块回退；CI 分别运行默认与强制便携测试。Parallel(1..16) 按输出行切分，独占输出切片、共享输入，不跨线程归约；小于32768 MAC 或仅一行/线程串行。无第三方运行库。基准 128/256/512 方阵预热、三次中位数、标量/分块/Auto/Parallel(4) 精确对照；实际 CPU 特性和速度以日志为准。未使用物理无 AVX2 机器、Windows 或用户电脑；无 FMA、线程池、batched matmul 或 GPU。
