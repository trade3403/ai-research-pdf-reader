## Windows x64 MSVC 本地构建

使用当前稳定 Rust MSVC 工具链及 Visual Studio Build Tools 的 C++ 链接器。仓库根目录下：

```powershell
cd rptranslate
rustc -vV
cargo fmt --all -- --check
cargo clippy --locked --offline --workspace --all-targets -- -D warnings
cargo test --locked --offline --workspace
cargo test --locked --offline -p rpinfer --features portable-only
cargo build --locked --offline --release -p rptranslate
.\target\release\rptranslate.exe self-check
```

self-check 仅合成数学测试，不加载实际模型。真实离线翻译需要完整验证的 RPModel-Mixed 包，模型和主程序分别部署；本阶段不发布模型或安装器。已在本地导入且验证的模型目录示例：

```powershell
.\target\release\rptranslate.exe translate-paragraph-int8 "D:\RPModels\mixed" geotechnical "We measured maximum strain." 1 128
```

强制通用 CPU 后端：
```powershell
cargo build --locked --offline --release -p rptranslate --features rpinfer/portable-only --target-dir target/portable
.\target\portable\release\rptranslate.exe self-check
```
